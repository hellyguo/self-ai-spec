# LLM 视角文档修订

## 目标

以 LLM 消费文档的视角，审视并修订 `skills/`、`lang-spec/`、`agent-templates/` 下的 Markdown，使文档可触发、可执行、可验证、相互一致。

## 修订维度

1. 可触发性：SKILL.md 的 `description` 说明能力、边界与触发场景。
2. 可执行性：命令、路径、输出物、退出条件明确。
3. 一致性：命名、章节、严重度分级、版本与日期统一。
4. 无歧义：消除相互矛盾的权威规则与重叠区间。
5. 上下文效率：模板统一引用方式，避免重复正文。
6. 结构完整：标题层级、代码围栏、交叉引用正确。
