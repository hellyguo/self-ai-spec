# 结构分派与相似范式重构配方

> 本文件补充 `SKILL.md` 中 D（去重）之外的两类轮次：P（相似范式）与 S（结构分派）。

## 1. 适用判断

| 现象 | 类型 | 是否适合循环内做 |
|---|---|---|
| 文本完全一致、无行为差异 | D 去重 | 是 |
| 结构相似、共享骨架、差异可参数化 | P 相似范式 | 视差异而定 |
| if/switch 按数值/字符串/枚举选择不同行为 | S 结构分派 | 有等价性证据时是 |
| 分支只有 1–2 个且行为简单 | — | 否，保持原样 |
| 分支依赖模块内类型、生命周期或静态状态 | — | 先决策，不在循环内做 |

## 2. 结构分派（S）配方

### 2.1 采集黄金输出

在改动前，用独立 harness 对**公开入口**跑代表性输入：

- 覆盖全部分支；
- 覆盖默认/未命中分支；
- 覆盖边界值（0、负数、空值、极值）；
- 记录输入与输出，保存为可重复执行的基线。

对于纯函数/无状态计算，优先用 `main` harness 或独立测试类；不要依赖生产日志。

### 2.2 定义接口

```java
private interface XxxHandler {
    Result handle(Input input);
}
```

- 接口只暴露稳定入参与返回；
- 不在接口中传递上下文对象，除非确有必要；
- 实现类/lambda 不捕获可变状态。

### 2.3 注册表替换 switch

```java
private static final Map<Key, XxxHandler> HANDLERS = new HashMap<Key, XxxHandler>();

static {
    HANDLERS.put(Key.A, input -> doA(input));
    HANDLERS.put(Key.B, input -> doB(input));
}

private static Result dispatch(Input input) {
    XxxHandler handler = HANDLERS.get(keyOf(input));
    if (handler == null) {
        return defaultResult(input); // 与原 default 一致
    }
    return handler.handle(input);
}
```

要点：

- 键优先使用枚举/字符/字符串常量，避免可变对象；
- 默认分支必须显式保留；
- 注册表静态初始化后只读；必要时用 `Collections.unmodifiableMap`；
- 分派前的公共逻辑（参数回退、空值处理、单位换算）留在 `dispatch` 外层。

### 2.4 对拍与测试

1. 重构后运行同一 harness；
2. 与黄金输出逐位对比，差异必须为零；
3. 补 JUnit 特征测试，锁定代表性输入与默认分支；
4. 若输出含浮点，使用明确的容差（如 `1e-12`），不要用 `==`。

## 3. 相似范式（P）分析

### 3.1 判断是否“同一范式”

看三件事，而不是文本相似度：

1. **控制流**：是否有相同的分支/循环/状态机骨架；
2. **数据结构**：是否操作同构的数据（字段集合、数组布局、消息结构）；
3. **生命周期**：创建、配置、使用、销毁顺序是否一致。

三者一致才可能共享骨架；任一不一致，先做差异分析。

### 3.2 差异分类

| 差异 | 处理 |
|---|---|
| 仅常量/字段名不同 | 参数化 |
| 仅调用函数不同 | 接口/函数式参数 |
| 数据结构不同 | 先统一数据模型，或放弃合并 |
| 生命周期不同 | 不合并，抽公共步骤而非整体 |
| 业务语义不同 | 决策账本，业务裁决 |

### 3.3 常见可抽象范式（Java）

| 范式 | 可抽象点 | 风险 |
|---|---|---|
| 静态计数器/缓存 | 通用容器 + 单一监视器 | 静态状态合并会改变隔离 |
| 线程登记/关闭 | 并发注册表 | 关闭顺序与异常传播 |
| 日期/数值格式化 | 线程安全 formatter 工厂 | 时区/舍入/本地化语义 |
| 固定数组/分隔串解析 | 读取器 + 槽位接口 | 越界、字段错位 |
| 序列化构造 | 工厂/线程内复用 | 实例可变、配置泄漏 |
| 多分支计算 | 接口+注册表 | 默认分支、前置逻辑 |

## 4. 不该做的抽象

- 只为 1–2 处重复引入新框架；
- 用反射替代明确的字段赋值，除非收益远大于可读性与性能损失；
- 把生成代码（`*Base`、DTO 生成物）手工重构；
- 把静态可变状态合并成跨模块单例；
- 在循环内做需要业务裁决的语义统一。
