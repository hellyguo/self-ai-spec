# 泄漏画像输出模板

> 用于“已定位到百万级同尺寸对象”的场景，把堆统计、对象画像、可达性、根因串成一份可直接交付的结论。
> 数字全部来自 core，不要写“约/可能”除非确实无法确定。

## 1. 样本与符号

| 项 | 值 |
|---|---|
| core | `<path>`（大小 `<n>` GiB） |
| 进程/构建 | `<exe>` build-id `<id>`；libc build-id `<id>`（是否匹配、sysroot 路径） |
| core 来源 | `si_signo=<n>` → gcore 活体快照 / 崩溃（二选一，写结论） |
| 堆区间 | `[0x…, 0x…)`（VA），文件偏移映射 `off = <x> + (va - <start>)` |

| … | … | … | … | 非主 arena 合计 `<x>` MiB（正常/异常） |

## 5. 可达性

| 抽样对象 | 全 core 指针命中 | 结论 |
|---|---|---|
| 首/中/尾 | `1`（仅自身自指） | 不可达 garbage，真泄漏 |
| 若非 1 | 需列出引用者地址与所属结构 | 缓存/队列，不能直接判泄漏 |

## 6. 根因链（代码级）

```
触发条件（状态/开关）：
  → 分配点：<file:line>  new/克隆 <对象>（<size> B）
  → 分发/处理点：<file:line>  查找失败/异常/提前 return
  → 释放缺失：<file:line>  只释放了 <A>，未释放 <B>
  → 累积速率：<n> 条/s × <h> h ≈ <n> 条 / <x> GiB
```
