# 数据库审查规则（所有语言通用）

## SQL 安全性审查

| 检查项           | 检测方法             | 重构建议       |
|------------------|----------------------|----------------|
| SQL注入风险      | 字符串拼接SQL        | 使用参数化查询 |
| 权限过度授权     | GRANT ALL PRIVILEGES | 最小权限原则   |
| 明文存储敏感信息 | 密码、密钥未加密     | 使用加密存储   |

## SQL 性能审查

| 检查项   | 检测方法           | 重构建议           |
|----------|--------------------|--------------------|
| 缺少索引 | 全表扫描查询       | 添加适当索引       |
| 索引滥用 | 过多或重复索引     | 合并索引、删除冗余 |
| 大表操作 | 无分区的全表操作   | 分区表、分批处理   |
| 结果集无界 | 无 `LIMIT` 且无有效 `WHERE`/分页 | 加条数上限、分页或收紧条件 |
| 全量加载 | 一次性把全表或全条件结果读进内存 | 游标/流式读取、按批处理 |

## 查询有界性审查（P0）

任何查询必须满足以下至少一条，否则判 P0：

1. **输出条数有界**：`LIMIT`/`TOP`/分页参数（且 `pageSize` 有硬上限）/流式分批（每批大小有上限）。
2. **查询条件有界**：等值或范围条件命中索引，能把结果集压到预期规模。

### 常见违规形态

| 形态 | 检测方法 | 处理 |
| :--- | :--- | :--- |
| 无条件全表查询 | `select ... from t` 无 `where`、无 `limit` | 补条件或补条数上限 |
| ORM 全量列表 | `findAll()`、`list()`、无分页的查询构造器 | 改分页接口，默认 limit |
| 分页参数无上限 | `pageSize` 由调用方任意传入 | 在服务层设硬上限（如 200/1000） |
| 导出/报表一次性加载 | 导出接口直接查全量再写文件 | 游标或流式读取，分片写出 |
| 条件来自用户且无界 | `in (...)` 列表长度取自请求且不截断 | 限制元素个数，超出则拒绝或分批 |
| 逐条取全量 | 懒加载 N+1，外层循环未分页 | 批量查询 + 分批处理 |
| 分页漏数据 | 结果集随处理收缩时递增 `start`/`offset` | 改按主键区间（`where id > lastId order by id limit n`） |

### 内存侧判据

数据库返回成功不代表应用安全：一次性把结果 `map` 成 `List`/集合同样会撑爆堆内存。审查时同时确认：

1. 结果是否全量驻留内存，能否改成分批消费。
2. 单批大小是否有上限，批间是否及时释放引用。
3. 是否存在先查全量再在内存过滤/排序的写法（应下推到 SQL）。

### 豁免

以下不算无界，不判 P0：

1. 聚合查询（`count`/`sum`/`max` 等）返回单行。
2. 按主键或唯一键取单条的查询。
3. 元数据、DDL、字典表等规模固定且可证明有限的小表查询。
4. 明确有界且已在代码中写死上限的查询（如 `limit 10` 的配置读取）。

## 表结构设计审查

| 检查项       | 检测方法           | 重构建议       |
|--------------|--------------------|----------------|
| 规范化不足   | 冗余数据、更新异常 | 实施第三范式   |
| 字段类型不当 | VARCHAR(255)滥用   | 选择合适类型   |
| 缺少约束     | 无外键、非空约束   | 添加完整性约束 |

## 数据库架构审查

| 检查项       | 检测方法       | 重构建议       |
|--------------|----------------|----------------|
| 单点故障     | 单数据库实例   | 主从复制、集群 |
| 备份策略不足 | 无定期备份     | 实施备份计划   |
| 监控缺失     | 无性能监控     | 添加监控告警   |
